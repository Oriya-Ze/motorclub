## למה זה קיים

בישראל חסר מקום אחד שבו תרבות הרכב חיה יחד: שיתוף רכבים, קהילה, מוסכים אמינים, מפגשים ומסחר.  
MotorClub מחברת **חברי קהילה** (נהגים, בונים, חובבים) עם **עסקי רכב** (מוסכים, שירותים, חנויות) באותה פלטפורמה — בלי שהשדרוג לעסק ימחק את הזהות האישית.

זה לא לוח מודעות בלבד, ולא אינסטגרם כללי. זה **רשת חברתית ייעודית לרכב בישראל**.

## שני סוגי חשבון

### 1. חשבון אישי (חבר קהילה)

כל משתמש מתחיל כאן.

- פרופיל אישי, פוסטים, עוקבים, הודעות.
- **«הכלים שלי»** — המוסך האישי: הרכבים שלו (לא מוסך תיקונים).
- כל רכב הוא **דרכון**: דגם, כינוי אופציונלי, תמונות, גיליון שדרוגים (build sheet), מעקב אחרי הרכב, «ספוטים», רכבים דומים, מדיה (כולל walkaround / סאונד כשיש).
- אפשר לתייג **עסק** על שדרוג — העבודה מופיעה אצל העסק תחת «עבודות».

### 2. חשבון עסקי (חנות / מוסך / שירות)

שדרוג בבקשה שמנהל מאשר — לא אוטומטי.

- דף עסק ציבורי נפרד מפרופיל החבר (`/services/:id`).
- אחרי שדרוג **נשארים** הפרופיל האישי והכלים. העסק הוא זהות נוספת, לא מחליף.
- קטגוריות: מוסך כללי, מכונאות, פחחות וצבע, צמיגים, חשמלאות, גרירה, דיטיילינג, ביטוח, השכרה, חלקים, אחר.
- בדף העסק: אודות, שעות, מפה, שירותים, מוצרים, ביקורות, אנליטיקה לבעלים, גריד «עבודות» מרכבים שתויגו.

**כלל מוצר חשוב:** «מוסך» בממשק החבר = אוסף הרכבים שלו. «מוסך» במדריך העסקים = בית מלאכה. לא לבלבל.

## מה יש במוצר היום

### פיד וגילוי

- פיד קהילתי עם פוסטים, תמונות ווידאו.
- **סיבוב (סטוריז)** — מדיה קצרה, יחס 9:16.
- **גילוי (Explore)** — תמונות, רכבים, האשטאגים.
- לחיצה ראשונה על מדיה בפיד → פוסט. לחיצה שנייה על המדיה בפוסט → מסך מלא.
- איכות מדיה לפי הקשר (פיד מול פוסט) ולפי רוחב חלון בווידאו — לא לפי User-Agent.

### קהילה

- **קבוצות** — נהיגה, יצרנים, תחומי עניין; כולל פרטיות קבוצה.
- **פורומים** — שאלות, טיפים, דיונים.
- **אירועים** — מפגשים ונסיעות.
- **הודעות** ישירות.
- **התראות** (עוקבים, בקשות עקיבה, פעילות על רכב וכו').

### רשת חברתית

- עקיבה אחרי משתמשים; חשבון יכול להיות **ציבורי** (ברירת מחדל) או **פרטי** (opt-in).
- בחשבון פרטי — בקשת עקיבה לאישור.
- בפרופיל: פוסטים, שמורים (לבעלים), הכלים, רשימת **עוקבים** ו**עוקב אחרי**.
- עקיבה אחרי **רכב** (לא רק אחרי אדם).

### שירותים ומסחר

- מדריך **מוסכים ושירותי רכב**.
- **חנות** (marketplace) — מוצרים של חשבונות עסקיים.
- תיוג עסק על שדרוג רכב → חשיפה בדף העסק.

### חשבון והגדרות

- הרשמה באימייל או Google.
- הגדרות: פרופיל, העדפות (כולל שפה וערכת נושא), עסק (לעסקים), חשבון, מנהל (למנהלים).
- בקשות שדרוג לעסק מטופלות במסך אדמין.

## עקרונות מוצר (לא לשבור בטעות)

1. **עברית ו-RTL קודם.** אנגלית קיימת, אבל המוצר ישראלי.
2. **זהות כפולה.** שדרוג לעסק לא מוחק מוסך אישי ולא מפנה את `/profile` לדף העסק.
3. **רכב = דרכון לשיתוף**, לא כרטיס מכירה כברירת מחדל.
4. **פרטיות opt-in לפרטי.** ברירת מחדל: פרופיל ציבורי.
5. **תיוג עסקים** בחיפוש — רק חשבונות עסקיים, אותו חיפוש כמו משתמשים (שם / יוזר).
6. **לא לערבב** מוסך-כלים עם מוסך-עסק.

## איך זה בנוי (לטכנולוגיה / AI שכותבת קוד)

מודול מונולית, לא מיקרו-שירותים.

| שכבה | טכנולוגיה |
|---|---|
| אתר | React 18, Vite, TypeScript, Tailwind, TanStack Query, i18next, PWA |
| API | FastAPI (Python), SQLAlchemy async, Alembic |
| פרוד API | AWS Lambda (קונטיינר) + API Gateway, אזור `eu-central-1` |
| אתר בפרוד | S3 + CloudFront |
| מדיה | S3 + CloudFront; העלאות presigned; עיבוד תמונות/וידאו ב-Lambda ייעודי |
| מסד | PostgreSQL ב-Neon |
| אימות בפרוד | Amazon Cognito (אימייל + Google). בפיתוח מקומי: JWT |
| סשן באתר | Access token קצר + refresh token; נשארים מחוברים עד התנתקות. נייד עדיין לא מיושם באותו אחסון מאובטח. |
| אימייל | Resend |
| קאפצ'ה | Cloudflare Turnstile (כשמופעל) |
| IaC | Terraform במאגר נפרד `motorclub-infra` |

נתיבים חשובים:

- `/` פיד  
- `/explore` גילוי  
- `/profile` ו-`/profile/:userId` פרופיל חבר  
- `/garage` ניהול הכלים  
- `/vehicles/:id` דרכון רכב (גם לגולש לא מחובר, לפי פרטיות)  
- `/services` מדריך עסקים, `/services/:id` דף עסק  
- `/community`, `/groups`, `/forums`, `/events`, `/marketplace`  
- `/settings`  
- `/privacy-policy`, `/terms-of-service`

קוד האפליקציה: מאגר `motorclub` (GitHub). לא לערבב עם קוד התשתית.

## מה עדיין לא / מה בפיתוח

- אפליקציית iOS/Android — מתוכננת; ה-API כבר תומך בסשן מתמשך, בלי לקוח נייד בחנות.
- אין עדיין מוצר «התנתק מכל המכשירים» כממשק נפרד מעבר ל-logout רגיל.
- ADR ישן מדבר על MotorHub + ECS; **בפרוד היום** זה serverless (Lambda + Neon + S3/CloudFront), לא ECS.

## איך לדבר על זה

**נכון:** קהילת הרכב הישראלית; רשת חברתית לרכב; דרכון רכב; כלים; מוסכים ושירותים; קהילה + עסקים באותו מקום.

**לא נכון:** עוד לוח יד שנייה; אינסטגרם עם מכוניות; CRM למוסכים בלבד; שהעסק מחליף את הפרופיל האישי.
